# Delibot mechanical CAD recovery

Recovered native Autodesk Inventor material from the original `New folder` directory. All 28 CAD files remain together in `inventor/` with unchanged filenames and contents.

## Assemblies

- `senior base design v1.iam`
- `senior 1.iam`
- `senior 1 - Copy.iam`
- `Assembly1.iam`

The collection contains 24 `.ipt` part files representing wheels, motor and wheel supports, pillars, plates, covers, a screen, and fasteners. `evidence/cad design.mp4` preserves the archived CAD video; it has not been visually inspected during recovery.

## Validation and next restoration step

Copies were verified against their original SHA-256 hashes. Inventor was not used to open the models, so the preferred final assembly, missing external references, assembly constraints, component dimensions, and geometry remain unverified. Start by opening `senior base design v1.iam` and `senior 1.iam` in Inventor, resolving references against this directory, and checking which assembly matches the delivered design.

After checking the assembly, use Inventor Pack and Go to collect external dependencies and export a STEP assembly plus clear overview images for a portfolio. The archive currently supports a CV claim about CAD part and assembly design, not verified manufacture, load capacity, structural analysis, or successful physical deployment.
